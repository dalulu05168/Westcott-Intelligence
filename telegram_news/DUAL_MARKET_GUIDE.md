# 罗马尼亚 / 法国双市场 Telegram 财经新闻（审核分支）

本模块 `telegram_news/dual_market.py` 是对原有单市场/12节点财经自动推送方案的**待验收升级版**，不是已经上线的真实 Telegram 送达证据。现有五项暂停任务、65人人物、剧情、签到机器人及老版新闻工作流均不被改变。

## 独立双国家通道

| 通道 | 标识 | 输出语言 | 本地07:30早报 | 关注市场 |
|---|---|---|---|---|
| Romania | 🔵 România | 罗马尼亚语 | Europe/Bucharest 07:30 | BET、BVB、银行、能源、当地利率 |
| France | 🔴 France | 法语 | Europe/Paris 07:30 | CAC 40、Euronext Paris、法国企业、银行、欧元区利率 |

两国日常通常相差一小时。**先各自在本地07:30发早报**（不同的真实时刻）；之后从**法国本地09:00至22:00，每小时整点**同时检查两国。法国09:00对应罗马尼亚10:00。每个实际时刻**最多2条 Telegram 消息**：法国1条、罗马尼亚1条；每条是「官网文章配图 + 对该国市场的分析 + 下一个关注点 + 原始链接」的一条图片消息。若只有一个国家有可核实新闻，只发一条；两国都没有时保持安静。

凌晨/周末不持续发送固定时段消息。工作日要另核对国家和美国市场实际休市日期、提早收市规则。本版只限制工作日，**尚未自动读取完整交易所假期日历**。不能把周一至周五等同于每个市场都开市。

## 入选规则：最重要，而不是最新随便选一条

1. 使用有来源的候选池（目前覆盖 **BVB 官方媒体公告、BVB 股票市场 RSS、BVB 上市公司财务披露 RSS、法国 AMF 公告 RSS、法国经济财政部 RSS、ECB 与 Fed 官方 RSS**）；记录源站地址、时间、标题与正文。**BVB官方财务RSS可提供大量公告候选，但仍须通过原始披露和图片校验；Euronext公司财报、美股个股盘前盘后公告尚未完整连接。**
2. 小时推送默认只接受过去60分钟内的新公告；07:30早报可以覆盖周末/隔夜，但不得重复上次使用的旧新闻。
3. 初版以本国相关性、政策宏观重要性、金融关键词、发布时间进行透明排序，选中本轮覆盖源中分数最高、能通过核验门禁的一篇。**评分≠能客观证明它是全球该小时影响最大的新闻**；要实现该承诺，需要覆盖全球重要事件的可靠新闻提供商与事件实时影响验证。
4. 同一事件如确实影响两个市场，可分别生成罗马尼亚版和法国版；各国的影响分析、下一步观察条件必须有区别。把可能的传导机制标为有条件的分析，**不冒充股票已因此上涨/下跌**。
5. 原文必须为可读取的官方网页，标题相互匹配；AI分析必须有原文40–200字符的原样证据摘录，新增数字若不在证据文本/合法行情数据中则阻止发布。**这只是自动一致性防线，不是人工审稿或真实性百分百保证。**
6. 图片必须来自**对应官方文章**的 og:image/twitter:image 元数据，限同一官方主域、可读取JPEG/PNG、有足够大小、不是通用Logo，且须确认站点允许重新发布。图片来源未核实/许可未确认，该篇不能推送；**不得用生成图片代替官网原图**。

## 昨夜美股三大指数

已配置调用 Twelve Data 的 `/quote` 数据接口，分别获取 **DJIA、S&P 500、Nasdaq Composite** 的有时点收盘价与涨跌比例；如果只有部分指标、口径错误、返回当前未完成的美国时段或供应商账号不支持这三个指数，则三项整体视为「待核实」而不生成数字。需要为 Three Index 确认真实供应商支持的代码（默认 DJI、SPX、IXIC，未实测账号权限）；必须核对数据供应商许可和时间戳，不能用搜索摘要或隔日旧报价凑数。

目前**还没有**实测美股盘前/盘后交易报价和美国企业最新公告的完整自动采集，这一项仍需要合规行情API（含延时声明）、上市公司投资者关系公告/财报源与独立事实审核。市场休市时不得标为当日正常交易。

## 私人聊天与手动验收

新工作流：`.github/workflows/telegram-dual-market.yml`

需要配置以下 GitHub **Actions Secrets**：
- `TELEGRAM_BOT_TOKEN`：既有 @NuvexaCheckBot 的 BotFather Token，不得放入代码和聊天；
- `TELEGRAM_CHAT_ID`：已确认属于用户的 **private** 数字 Chat ID；每次图片发送前会再次验证 chat.type=private；
- `OPENAI_API_KEY`：新闻分析生成专用 API Key；
- `TWELVE_DATA_API_KEY`：需具有三大美国指数报价权限的行情 API Key。

GitHub **Actions Variables**：
- `OPENAI_NEWS_MODEL`：项目账户可以访问且支持结构化 JSON 输出的模型；
- `OFFICIAL_IMAGE_REUSE_APPROVED=true`：在核对图片使用授权后才能设置；
- `TELEGRAM_DUAL_MARKET_ENABLED=true`：只有全链路测试通过后才设置；
- 保持旧 `TELEGRAM_NEWS_ENABLED` **不为 true**，以免单市场旧版与双市场新版重复发送；
- 如三大指数在账户中采用不同代码，可配置 `US_INDEX_DOW_SYMBOL`、`US_INDEX_SP500_SYMBOL`、`US_INDEX_NASDAQ_SYMBOL`。

默认**不开启任何新自动发送**：仅手动 `workflow_dispatch` 允许 `dry_run=true` 预览；所有真实发送必须先有明确启用变量、图片许可变量和机器人/行情/AI密钥。

### 必须走通的验收

1. 离线测试：`python -m unittest discover -s telegram_news -p 'test_*.py'`。
2. 真实新闻抓取回归：逐条检查BVB/AMF/Fed/ECB原文、图片URL是否对应同篇文章，校验图片的再发布授权。
3. API回归：取真实前一美国交易日已收盘的三大指数；核对源时点和涨跌基准。
4. 真实AI审核：至少测试罗语、法语同一事件的不同本国市场影响与下一步指标，拒绝幻觉/重复事件。
5. Telegram**私人聊天**手动送达：核对🔵/🔴、图片、内容和单小时两条上限；消息ID和去重状态入库；重跑不能重复报。
6. **单旧新版切换**：关闭旧自动推送，确认旧聊天五项暂停任务未恢复，新流程灰度运行至少一个交易日，检查日志与真正Telegram到达时间。
7. 完成以上所有步骤后才能把双国家工作流标记为正式运行。GitHub Actions cron 有延迟/漏触发可能，不保证绝对准点。

## 界限

- 代码中「财经市场影响」是有条件的研究方向，不是确认已有的价格反应、投资建议或实盘指令。
- 不能仅凭包含 `og:image` 就证明图片可被法律上任意转载。
- 在官网没有可复用的图、新闻不是实质新增、源页不可读、数据过期或者语言分析证据不足时，**不发布**，并记录过滤原因。
- 不修改现有的65人人物档案、记忆、正式Google Doc和五项暂停任务。
