# ELLERY WESTCOTT｜财经新闻推送内容分析与后续追踪 V1.0

生效对象：既有 GitHub Actions 审核账本与 Telegram 新闻发布通道。此文件只规范播报文案与审核；**禁止**调整定时 cron、国家组别、Telegram 机器人/群组/线程/密钥，禁止恢复暂停的五项旧任务。保留免费策略：不能依赖收费 OpenAI API；无法完成外部语义核验时，保留 `DRAFT_UNCONFIRMED`/`HELD`，不可擅自改成 `CONFIRMED`。

## 逐条新闻的内容义务

1. **📌 事件概述**：明确来源、主体、地点、时间、关键事实及与此前信息的差异；只写原文支持的内容。事件实际发生时间未知时只报「官方发布时间」，不将发布时间冒充事件发生时间。
2. **🔍 核心解读**：把重要性解释成可理解的传导链条（例如政策—融资成本—盈利预期—估值），清楚标识由事实推演的假设。
3. **📈 市场影响**：按罗马尼亚 BVB/BET/RON、法国 CAC40/欧元、美国三大股指和相关全球资产的*实际关联*解释，分开写「已证实反应」「潜在影响」「尚不确定」。无经核实行情时写暂无确认反应，不捏造股价、成交量、收益率、资金流向或涨跌。按高/中/低说明理由，区分短期及中期。
4. **🎯 后续关注重点**：严格 2—3 条；每条包含可验证的指标/机构公告/财报与可判断的时间、发布日期或触发条件，不能写空话或凭空捏造日期。
5. **🔔 判断变化条件**：分别说明哪些新事实会增强、削弱/推翻、验证当前判断。
6. **来源与时间**：所有事件事实必须指向官网文章原始 HTTPS 地址、发布时间、正文快照和逐字可定位证据；来源可访问但不代表事实自动核验通过。

## 与发布器的结构映射

新的待审账本必须标注 `content_standard = "ELLERY_WESTCOTT_NEWS_V1"`，并在既有 `claims` 的已发布文本中分别标注：
- `content_section = "event"`：新闻标题、地区、时间、影响程度、事件概述（`kind=fact`）。
- `content_section = "interpretation"`：核心解读。
- `content_section = "impact"`：影响程度理由、三种影响状态及短期/中期。
- `content_section = "watch"`：2—3 条可追踪观察点及时间/触发条件。
- `content_section = "change"`：增强、减弱、验证条件。

后四条均为 `kind=analysis`，必须具有 `target_country`、`conditional=true`、`boundary_text`、来源证据与 `premise_claim_ids`。原有 `local_impact_claim_id` 对应 impact，`watch_next_claim_id` 对应 watch。发布内容只能由已审核 claim 的 `text` 产生；不可在发送阶段用自由生成内容拼出未经审核的分析。

字段具体的格式、标题、数据完整性、2—3 关注点数量以及禁用空洞结束语由 `integrations/telegram/news_analysis_v1.py` 检查。该验证只验证结构和一致性，**不自动证明语义、影响方向、市场数据或来源真实性**；依然必须通过 `scripts/news_release_gate.py`、`editorial_policy.py` 与发送前原文复核。

## 追踪与去重

用既有 `event_key` 锁定同一事件、同一国家和小时窗口。同一事件不同附件或 URL 不得伪装为新消息；仅有实质性官方进展方能再次进入候选比较，并解释「前情→本次新增→影响判断变化→下个验证节点」。在延续稿中复用该事件的稳定身份，不能为躲过去重更换事件标识。已有 DELIVERED/PENDING/UNKNOWN 送达审计照旧由发布器拦截。

后续重点仅定义下一轮应主动检索的对象，不代表系统已创建自动化追踪提醒；真正的追踪执行和触发记录仍须以运行日志、审核结果和真实回执为准。

## 发布及验收

正式发送工作流设置 `NEWS_ANALYSIS_V1_REQUIRED=1`；对未带 V1 标记、缺标题/事件/解释/影响/观察条件/变化判断的账本，直接 `HELD`。两项现有发布路径均使用此门禁；不修改任何时间节点或 Telegram 参数。不能通过编造内容补齐字段。旧账本不会被静默升级为 V1，也不能自我批准。编辑和预览可离线进行；合入主分支前必须运行仓库离线测试与 `python scripts/validate_repository.py`，且需独立核验事实。

**当前限制**：已连接的主审核发布器按国家区分 RO / FR；美股相关及 RO+US / FR+US 早报的另一套代码路径，需要分别纳入相同播报要求才能称为全链路覆盖。在此之前，不能宣称美国市场所有新闻已经被强制校验；不得把本次内容变更冒充 Telegram 真实送达。
