## 更新什么
- 持久规则：保留原话、日期、适用范围、规则ID，区分确认与建议；规则变更记录supersedes，旧证据保留。用户仅改变当前任务时，不自动推广到所有流程。
- 正式剧情：用户明确采用后保留日期/时段、人物编号、完整原文、来源位置和版本；长稿按日期分文件，建立索引。重复导入同一来源不重复累计。
- 人物状态与课程：只从已采用原文派生，反链到原话；角色说买入/作者跟推荐标注不等于现实成交。缺少价格、数量、家庭信息就保持未知。
- 当前草稿：单独记录，不进入正式人物历史。确认采用、写入文档、实际发群分别报告。
- 每次仓库写入后用真实连接器读回SHA/内容；若GPT没有仓库写权限，就报告尚未入库，不能说已经永久记住。并发更新先比较版本，不覆盖其他窗口变化。
