# 罗马尼亚金融市场与美股/国际事件联动采编规则 v2.3
生效：2026-10-20（罗马尼亚时间 Europe/Bucharest）；用户新增确认。适用五Skill、资讯助理、日内早报/盘前盘后、课程取材和群聊候选。与历史规则冲突时，本文件在“罗马尼亚与美国/国际新闻联动”主题上优先；原有人物授权、课程时段、双市场股票研究、新闻数量/去重、发布权限及 DRY_RUN 均不变。

## 核心定位
- **罗马尼亚市场为核心**：以 BVB、BET 及本地银行/能源/公用事业/企业盈利、BNR/INS/罗马尼亚政策为首。美国股市及其他国际市场**必须列为每日常规候选来源**，重点关注那些已经影响、正在影响或有清晰合理渠道可能影响罗马尼亚金融市场的重大变化。全球重要性本身不等于对罗马尼亚有影响；无可说明的关联不硬塞入当日主线。
- 候选不得只来自美国：必要时检查 ECB、欧盟、欧洲主要市场、全球能源与大宗商品、汇率、贸易政策、地缘冲突等。非美事件仅在影响罗马尼亚的可信渠道充分时纳入；不按国家配额凑新闻。
- 美国三大指数（纳斯达克综合、标普500、道琼斯）、行业及重大企业事件是国际情绪与经营环境的线索，不能直接用指数涨跌推断 BET 或个股方向；相关性、同时发生不等于因果性。

## 应优先核查的传导渠道（举例，不是已发生事实）
1. 美联储、美国 CPI/就业、美债收益率、美元及风险偏好 → 国际融资/资金定价、EUR/RON与USD/RON、欧洲货币及银行信贷环境 → TLV/BRD 等实际数据；必须分清美元、欧元与罗马尼亚列伊的具体环节。
2. 美国科技股、AI/半导体业绩和资本开支 → 欧洲供应链、订单/投资、风险偏好 → 与罗马尼亚相关的有据可查企业或行业。**不得虚构罗马尼亚股票必然直接受益或受损。**
3. 国际油气、电力、能源运输及政策 → SNP、SNG、H2O及下游企业的原料/能源成本、销量、利润率。生产商与消耗方可能受不同影响。
4. 美国/欧盟关税、贸易与重大地缘事件 → 出口、物流、工业需求、投资与本地生产经营；明确受影响的行业、合同/政策适用范围和兑现时间。
5. BVB、BNR/INS、本地公司披露和实际行情反馈反过来验证或推翻上述预期；本地已核实证据优先于外盘情绪类推。

## 分级：已证实市场反应 vs 可能的影响
- `ROMANIA_VERIFIED_RESPONSE`：可确认罗马尼亚市场、企业或政策已经出现具体变化。写清具体主体/标的、证据来源、事件和数据时间、涨跌比较基准、阶段。只有额外具备足够独立证据才可声称海外事件**导致**该变化；否则只陈述事实与可能关联，不作因果断言。
- `ROMANIA_POTENTIAL_CHANNEL`：海外事件已核实、罗马尼亚影响**尚未被市场或公司证实**，但存在具体合理渠道。明确“可能/如果/需要观察”、成立条件、时滞、相反情形与待核指标；不得写成“已经影响”。
- `NO_DEMONSTRABLE_LINK`：找不到可信的罗马尼亚传导渠道，或证据不足，留内部观察，除非用户明确要求纯美国新闻背景，否则不进入罗马尼亚主要资讯。
- 已知价格反应与已知因果关系是两项独立判断；禁止把“美元上涨”“纳指上涨”“外盘情绪改善”直接写成 BVB 上涨原因。所有时间和交易阶段必须一致。

## 每条入选国际新闻的后台证据字段
沿用 event_id、claim_id、source_refs、published_at、quote_as_of、market/session_phase、comparison_baseline、new_evidence、why_today、who_affected、follow_up_conditions，并补充：
`origin_market`、`romania_relevance`（上面三个状态之一）、`transmission_chain`（至少一个具体中间环节）、`romania_targets`（BVB行业/公司/经济指标；未知则不得硬填）、`evidence_for_romania_response`（已反应的可核验来源，潜在情形填 null）、`impact_conditions`、`counter_conditions`、`next_check`。
不能得到来源正文、数字基准和时点时留在待核区，不能因“国际重大”跳过事实门禁。重要事件市场归因沿用至少两个独立可靠证据的现有规则。

## 每日时段与内容顺序（罗马尼亚时间）
- **07:30早报准备 → 08:00开群**：先核实上一个美股交易日官方收盘及盘后、美国宏观/企业重大新事件；接着筛选对当天罗马尼亚市场可能传导的线索，配合BVB盘前/BVB上次收盘与本地公告。若美股休市/尚无本次可靠报价，准确标注状态，不补造数据。
- **上午罗马尼亚盘前至12:00**：优先讲本地消息、BVB开盘/实际交易观察，逐步核对隔夜国际事件对本地行情是否出现证据支持的反应；未出现反应就说明仍待观察。
- **14:00下午至尾盘**：承接上午尚未回答的问题；关注BVB盘中/收盘、美国当日盘前宏观与企业事件及欧洲政策。美国真正开盘后按当日时差核对官方/可靠的常规盘报价，不把美股盘前冒充正式开盘。
- **16:00及19:30活动、20:00课程与21:00答疑**：原活动/先生授课时间不变；新闻仅在与活动或已确认课程主题有直接关联时作为简短背景，不机械重复新闻；由资讯助理播报，先生依据已讲课程和证据作教学分析，不在白天冒充先生市场点评。
- 美国夜间盘后新公告进入下一个罗马尼亚早报候选池，绝不倒写入当天早先时段。跨美欧夏令时不同步期间重核实际市场开闭市时间。

## 输出原则
- 资讯助理用自然口语讲：发生了什么 → 为什么罗马尼亚投资者需要知道 → 已经有何实际证据/仅存在何种可能渠道 → 哪些条件与数据值得继续看。这是**思考顺序而非固定四段模板**。
- 每天仍优先选择1—2条真正重大、有新证据的主线和必要补充；旧闻没有实质新变化则不重复。BVB与美国各一次股票研究是另外两个有条件的内容位置，顺序需用户指定，不可拿新闻顶替，更不可承诺交易。
- 成员按已采用个人记忆从01—42自然讨论不同环节，允许怀疑、沉默及互答；没有证据不能宣称自己赚到/已经按新闻买卖。43—65仍不出场。
- 新闻、市场观察、虚构成员观点、技术课程各自区分；任何未经用户批准的群消息不等于已发布；维持 DRY_RUN、原发送许可和自动任务停用状态。

## 最小质量检查（提稿前）
1. 新闻主体、原文、日期、数字、时区、交易阶段已核验？
2. 关联的罗马尼亚企业/行业/指标和中间传导路径是否具体，而不是直接套涨跌？
3. “已证实反应”和“可能影响”是否明确分开？市场同时波动有否误称因果？
4. 是否解释下一次可检验的数据、公告、量价或条件，并避免旧闻重复？
5. 是否尊重本地优先、现有节点/活动/双市场研究与自然对白，以及发布状态限制？
