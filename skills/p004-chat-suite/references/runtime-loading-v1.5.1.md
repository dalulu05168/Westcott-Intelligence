# v1.5.1 实际加载与候选创作

本次针对上午真实正文反复报告人物资料缺失的问题。原身份/profile/已采用历史文件不修改。

首先读取本任务实际可访问的Skill与资料；网页任务没有本地路径访问时，不用Windows路径充当已加载来源。原五项完整替换提示词已内置`runtime-context-v1.5.1.txt`的同一资料快照，包含65人完整11列身份、65人语气参考及可用已采用记忆；这解决本次准备包的外部读取依赖，不代表线上已保存成功。

内置快照来自v1.5固定提交，记忆仅覆盖2026-10-12已整理记录；不包含之后未取得的历史，不应称最新全量记忆。后台区分INLINE_SOURCE_SNAPSHOT与REMOTE_FILE_READ，并记录实际选用人员和已读消息ID。内置摘要不能冒称六份Skill原文均已远端读过。

有已确认身份即可创作明确未采用的候选。profile的identity_approved_by_user=true表示身份已确认；approved_by_user=false与voice_status=CREATIVE_DRAFT_NOT_USER_APPROVED表示新语气尚未正式采用，不能据此将整个候选创作关闭。缺少历史只禁止历史断言，不禁止新人问当前事实。身份缺失时先选身份可用的其他人；全员身份都缺失才报告加载失败，不能编造编号。N01永远不生成成员对白。

候选仍需3–6条按需选择、独立感受、口语差异和基本事实核验；未选不写记忆。新版上线后还要看实际正文，版本标记或哈希匹配不是口吻与运行通过证据。

应用时逐项读取原线上任务全文，保留任何较新有效修订，再只更新prompt。保持ID、日程、时区、启用、通知和邮件设置。遇到提示词长度限制不得静默截断；停止该项应用并报告实际限制，改用任务可访问的附件/Skill后再验收。当前最大允许长度未由接口确认，不承诺本包一定被平台接受。

完成线上保存后独立读回全文及设置，再按真实新闻交付验收N01、N06、自然助理稿与人物候选。没有可用写入接口或浏览器工具被停止时，包标PREPARED_NOT_APPLIED，不新建替代任务。
