# v1.7｜盘前/盘后必查、新闻吸引力与资讯助理深入拆解（2026-10-14确认）

适用 ELLERY WESTCOTT 每日新闻选题、上午/下午BVB与美国股票研究、虚构教学群聊。优先遵循用户当前限定的01—42号可出场、人物真实已采用记忆、一次BVB与一次美国股票研究、时间顺序由用户通知。本文是内容创作和核查协议，**不等于已经部署自动盘前/盘后扫描、定时发布或真实交易**。

**时差和窗口规则：** 按事件交易所当地时区确认发布时刻，并转换为 Europe/Bucharest 用于场次安排；美东与罗马尼亚夏令时不同步的周必须核对当天时差。美国在布加勒斯特夜间才发生的盘后新公告，可进入次日早间线索池，绝不倒写进已经完成的当天早间/下午剧情。周末或假日也要判断市场休市，不编造盘前盘后成交。

**每次采编后台检查表（不直接贴到群内）：** `market`、`session_phase`（PREMARKET / REGULAR / AFTER_HOURS / BVB_PREOPEN / BVB_OFFICIAL_CLOSE / POST_CLOSE_DISCLOSURE）、`exchange_local_time`、`bucharest_time`、`source_url`、`issuer_or_agency`、`published_at`、`quote_as_of`、`has_verified_quote`、`material_new_fact`、`status`（CONFIRMED / PENDING / CONFLICT）、`why_today`、`next_check`。没有读到可靠正文或行情的栏目保留待核，不可硬编。

## B. 事件必须具有“有事实依据的吸引力”，不是标题党
每条备选事件先检查：
1. **真实重要性：** 会否实质改变盈利、利率、企业现金流、成本、需求、行业格局、估值或市场预期？是否有可靠来源？
2. **新鲜变化：** 与市场事先预期、上次披露、上个报告期或上次讨论相比，**到底哪一点变了**？没有同口径对照不可声称“超预期”。
3. **与目标市场关联：** 清楚说明对BVB具体板块/企业或美国行业/指数的潜在作用路径；没有关联的不硬拉进群聊。
4. **可讨论的角度：** 是否能自然引出不止一个合理观点，例如盈利数字强但现金流仍待核、能源企业受益而运输成本承压？不靠人为挑衅制造冲突。
5. **后续跟踪价值：** 是否有接下来可验证的财报项目、指引、利率决议、量价表现、关键公布时间或失效条件？

优先选同时具有**来源可信＋实质影响＋有新信息**的事件。仅有吸睛词句、猎奇、未经证实热搜、政策传闻、昨日同一数字、空泛乐观/恐慌，不进入主线。每天常规重点1—2条主线，不必把四组窗口中发现的素材全部播报；重要盘前/盘后新闻若被选中，应在当天适合的窗口说明“为什么现在值得讲”。

## C. 资讯助理的专业讲解方式——一个事件讲透，而非报标题
助理先在后台完成六个思考层，最终只选与事件真正相关的层次，用自然口语把一条新闻讲通顺，不用固定机械小标题：
- **事故事实：** 谁、什么事、何时公布、已确认核心数据/决定；明确消息类别和交易时段。
- **相对于什么改变：** 相比市场一致预期、公司指引、上期数据、前收或上次新闻，变化的幅度及可比性。无可信比较基准就不比较。
- **传导机制：** 如何进入企业收入、成本、利润、现金流、估值、融资成本或风险偏好；海外事件影响BVB必须点明中间环节，不能直接类比。
- **差异化影响：** 哪些企业/行业可能受益、哪些可能承压、哪些影响尚不清楚；不把整个银行/能源/科技板块说成同涨同跌。
- **市场真实反馈：** 如有可核验反应，区分前收/盘前/常规盘中/盘后及成交时点；没数据就不把上涨、下跌、成交量或资金流当事实。
- **下一步要看什么：** 提出两到三项**与该事件密切相关且可核实的观察条件**，例如下一份净息差/不良贷款、公司指引与实际收入、订单/毛利率、Brent及成本变化。说清如果A发生意味着什么、若未发生原判断哪里站不住；不承诺涨跌或给无证据买卖价。

**对话牵引：** 在内容自然结束处提出有价值的具体问题，能让不同职业背景角色接话。例如同一银行财报可由银行职员关心净息差、企业主关心信贷成本、会计师关心利润与现金流差异；**不要强行每次三人齐上阵**。已经被成员提出的真问题优先回答，不再重复助理自己问过的问题。可以让成员连续互答、跨时段补充、暂时不回复。人物只能01—42号，必须实际读取个人历史和双方已采用互动记忆。

## D. 采编与发布衔接
- 日前：美国上个交易日盘后 + BVB上一交易日闭市后新披露先入待选池；核对今天宏观与财报日历；盘前候选不等于证实有重大行情。
- 上午：核验BVB盘前披露与预开盘/开盘阶段；按用户指定安排其中一个市场的股票研究，若美股研究安排在当地上午，须如实使用前一收盘/已确认盘前资料。
- 下午：查BVB盘中与尾盘、美国盘前及实际已开放交易的阶段，按用户指定安排另一市场股票研究；美国市场状态取决于实际当日时差，不按固定时刻假设。
- 傍晚或闭群前：BVB官方收盘与闭市后披露按可用性核查，夜间美国事件如发生于社群闭群后，只入**下一日候选池**；没有实际后台夜间扫描时不能宣称已经检查完成。
- 新闻审核通过后才生成助理稿、成员对话和股票研究稿；未核验不得因事件“很吸引人”而补入失真的数字、解释、讨论或图形。
- 为每个选中新闻内部写一条 `reason_to_discuss` 和 `follow_up_conditions`；完成稿前审查与以前新闻有无重复、成员是否真的在回应互相的观点及助理的解释是否具体。
- 两次市场股票研究发布是独立内容位置，不能用盘前/盘后新闻数量替代。用户当天未指明上午下午顺序则暂停实际发布安排，先准备候选素材。

## E. 简短示例：助理如何拆解（假设素材，不是新闻或行情）
“假设一家银行披露净利润改善，但贷款业务的增长并不明显。这里最需要分清的是：利润增加，究竟来自贷款扩大、净利息收益改善，还是一次性的会计项目？这决定了增长能否延续。接下来我们可以看净息差、不良贷款以及下一季度业务指引。如果这些关键指标没有同步改善，仅凭净利润一个数字，还不能认定经营趋势已经全面转好。大家更在意利润本身，还是这些利润的来源？”
此例只演示事实与分析的拆解顺序；真正播报不得将假设案例包装成今天发生的新闻。
