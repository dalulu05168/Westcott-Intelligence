# 当前写作硬规则（v1.6补充，2026-10-14 更新；最新优先参见 daily-editorial-and-memory-v1.6.md）

此文件是五合一当前会话的统一规则；用户后续明确修订时更新正文和变更记录，覆盖冲突旧描述。这个聊天页面用于本项目写作、规则维护和每日最终稿记忆整理；不会因此在无人发消息时后台执行。

## 新闻采编与重大事件

先核对原文来源、日期、罗马尼亚发布时间、事件发生时间、行情观测时间、数据基准与客观热度，再去重、过滤政治立场与无关内容，按发布时间顺序排队。采集时刻不等于发布时间，今天报道不等于事情今天发生。

优先1–2条重大事件主线加必要补充；没有合格新增不凑数。旧闻无新事实、新行情反馈或持续重要影响则退出。不得超过当前节点实际时间，不重复旧新闻冒充更新；必要旧背景明确标注。新闻新鲜和有热度是不同条件。

热度按 editorial-gate.md 的已确认量价与传播证据判断。没有热度证据的普通车展、产品发布、公司宣传不能直接进入主线。重大财报、资本事项、宏观数据等独立重要性可按既有口径进入候审，但必须写明独立触发依据，不能把所有企业消息都称重大。无证据不声称热门或前三。

## 资讯助理与表达

标签准确使用 `===== 资讯助理 =====`。女助理直接说事件、必要数字和变化，随后简短分析与生活、企业、经济和罗马尼亚市场有关的可能影响及观察条件。每条消息一个重点；不固定一条新闻必须拆成几条消息。

不使用“刚才讲到……再看一条”“罗马尼亚时间今天……某网站报道……”作为重复开场。完整来源及时间放后台核验区，保留可点击原文；群内钟点只写HH:mm；事件日期、计划期限、报价时点等理解所必需的时间保留在正文。不省略影响事实判断的重要限制。不决断涨跌、买卖、机构身份或收益。

## 自然互动与选角

不套固定人数或发言顺序。完整“资讯助理讲新闻→两个成员→资讯助理补充→一个成员”循环全天最多两次，不必用满；计算需覆盖当天有效对白和本轮候选稿，未知采用总数不得声称已达日配额。

可连续发布资讯、无人回应、成员互答、隔几条或后续节点回应、接前话题或适量日常。无需每条最后总结，不强制争执或和解。

65人完整身份档案继续保留，但当前只准01—40号参与剧情，按完整档案、兴趣、当前可参与性及有效记忆选角，查看近期出场记录；不围绕03和33反复使用。接续当前稿先让03和33休息，无固定冷却天数，不按编号轮流点名，不为换人添加无关发言。句长、语气、表情、知识程度要各自不同。新人/老人仅使用已确认分类，不能从编号推断。

成员标签为编号加已确认性别，正文白话。每人持仓、亏损、关系和成长仅来自本人有来源的有效内容，不把他人经历或未采用稿写成记忆。

## 全天与课程

不设置全天人物消息配额；适宜群聊节点提供3–6条候选供选择，N01不生成成员对白。12节点和既定每周活动继续执行；美股在国际节点区分市场阶段，不混用异步旧行情。先生仅20:00、21:00，周一三五技术，周二四理念。

## 日终定稿、记忆及仓库

用户提交修改后的全天最终稿即按本次授权整理并上传仓库，无需重复询问是否归档。保存原文、实际段数、节点、事实出处、全局主线、逐人观点/学习变化、未解问题及次日线索；消息使用稳定ID并记录原稿位置。以最终稿替代当天被修改/删除的草稿事实，保留修订版本与来源；不要重复累计同一事件。

写入 `memory/daily/YYYY-MM-DD/` 的完整原文及结构化记录，`memory/long-term/global.md` 和 `memory/long-term/members/NN.md` 仅更新有依据的记忆。长期记忆引用日期、节点及消息ID。角色基础档案不随日报自动改写；市场数据过时不作为新一天实时报价。缺少记忆文件视为空历史，不补造。

仓库仅同步本隔离五合一项目的资料和记忆，不混入旧人物或采集器软件。上传前核对目标仓库、隔离路径和分支，保留提交SHA、文件路径和同步时间并回读。采用不等于实际发送。权限/接口失败时保留本地资料并说明未上传，不声称已保存到GitHub；新会话仍需加载资料包。
