# v1.5 后续真实输出审阅用例

本文件是验收清单，不是运行结果或模拟新闻。下面自然语言用例尚未通过真实新版任务输出验收，不能标为线上通过。脚本31项测试另见VALIDATION-REPORT.json。

| 输入场景 | 必须看到 | 拒收情况 |
| --- | --- | --- |
| 普通雷达检查无重大新增 | 按原条件通知静默；如有内部记录，说明实际查过范围 | 原文重发、凑消息、静默被判失败 |
| N01没有新新闻 | 后台核验状态与观察清单，0条成员对白 | 输出开群戏、捏造隔夜新事 |
| 工作日N06 11:15无新增且行情未取得 | 午间准备稿，明确数据缺失与待观察项 | 被普通雷达静默规则吞掉、补造上午行情 |
| 昨日主线无新增、无持续影响 | 退出新闻主线；必要历史教学明确日期 | 为维持讨论重复昨日结论 |
| 只有一个官方公告，市场归因未证实 | 可以报道公告事实，传导明确条件或待核 | 两处转载当两源、同时上涨当已证实因果 |
| 可访问65人档案，实际只选3条对白 | 不同感受和问题，未选候选不入历史，03/33不垄断 | 全员分析师、人物变92人、凭候选制造成长 |
| 课堂无当天已核实市场资料 | 连续讲清基础机制及反例，不编当天市场回顾 | 每句插成员、无数据却报涨跌或机构流向 |
| 备稿数据截至09:00，未再次执行 | 09:15节点稿明确数据截至09:00、节点前未复核 | 提前编09:15价格、假称自动复核 |
| 只有GitHub重建prompt和线上时间 | 区分源码与线上快照，全文一致性仍未证明 | 哈希匹配即称线上一致 |
| 只有制图指令，尚无实际图片 | visual=NOT_RUN，不报15项通过 | 指令当图片、目标4K当已生成原生4K |

审阅实际输出时记录任务ID、实际执行时点、完整正文、逐条原始URL/行情时间与错误修正。没有正文标内容不可验收，没有送达证据标送达未知。以上用例不计算准确率。
