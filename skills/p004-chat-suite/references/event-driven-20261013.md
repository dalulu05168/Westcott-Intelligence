# 2026-10-13 重大事件采编规则（本地审阅版）

本规则落实当前用户修订，冲突时优先于旧三条一批、地域限制和机械节点轮换。规则文件不等于已运行的采集或推送服务。

早间筛昨晚至今早的新事件；白天至晚间持续核查全球重大财经消息。地域不限，判断前提是股票市场传导及罗马尼亚投资者相关性。没有新事实、新数据或持续市场影响，不反复讨论昨天的新闻。无合格事件不凑数，合格事件优先单独及时处理；最多三条仅为批量上限。

事件触发依据：宏观政策和数据、重大财报及指引、资本事项、监管司法事件、能源供应或行业技术变化等，必须有可追溯证据说明影响链条。股价已经波动不是唯一准入条件，但潜在影响不得写成已发生市场反应。事实、市场观察、推断、未知分开记录；事件重要性不能由搜索排名或转发量替代。

每条事件用稳定event_id；同源转载不算独立核实。记录首次发现、事件时间、原文发布时间与更新时间、核查时间、来源URL、原文依据、涉及证券/行业、数据单位及基准、行情观察时间、已发布版本及新增事实。无实质变化只更新内部核查记录；更正错误必须明确标记，不能静默覆盖历史。

默认计划每小时核查；实际监测窗口、调度器和通知渠道待核实。不得把每小时轮询说成实时或全天候扫描。重大事件在当前扫描发现并核验后立即进入配图与播报流程，不等节点；延迟如实记录。12节点保留，提前15分钟备稿，到节点前复核；07:50的准备时点为07:35。备稿不强制发布、不强制更换新闻、不覆盖尚未到来的事实。

资讯助理用自然普通话，先说事件和必要数字，再解释对盈利、估值、利率、成本或资金风险偏好的传导；给观察方向、验证条件与反例，不保证涨跌或收益。判断依据不足就降低结论强度。群内时间只用HH:mm；理解事件所必需的日期、报告期和期限保留；完整带时区时间存内部证据。来源链接置文末，避免重复开场及空泛总结。
