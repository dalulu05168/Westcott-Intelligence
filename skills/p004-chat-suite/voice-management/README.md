## 立即使用
1. 在 GitHub 下载单文件 [voice-manager.html](voice-manager.html)（Raw → 保存），然后在电脑浏览器打开，无需服务器或 AI API Key。内含65人正式身份及261条已采用对白片段，支持搜索、证据查看、逐人审批、可追溯回滚、JSON备份和生成规范化人物写作指令。
2. 人物语言规则只有勾选并点击「确认并保存」后，才会在浏览器本地被标记为批准。批准结果不会自动更新 GitHub；请导出JSON作为共享和跨电脑持久备份。**原始身份不可在管理页改写。**
3. 可选：已有 Humanizer Studio v1.2 可通过「导入人物库 JSON」读取本目录 [humanizer-studio-import.json](humanizer-studio-import.json) 中65个人物+4个工作人员的独立档案。导入会并入浏览器当前档案，导入前建议先导出备份。
4. [SKILL.md](SKILL.md) 给 ChatGPT/Codex 写稿阶段提供严格调用方法，强调先读取最新Doc与角色正式身份，再用已批准规则匹配口吻。
